# ADR-001: Выбор стека приложения-оркестратора

## Статус

Принят

## Контекст

Приложение-оркестратор управляет AI-агентами (Claude Code, Codex) для автоматизации цикла разработки. Необходимо выбрать язык и фреймворк.

## Решение

**Python ≥3.11 + Claude Agent SDK.**

Обоснование:
- Claude Agent SDK — официальная библиотека с хуками (принуждение), субагентами (раздельные контексты, разные модели), учётом токенов
- Python — основной язык SDK, зрелая экосистема для автоматизации
- Инструменты качества: pytest, ruff, mypy — зрелые, быстрые, строгие
- Agent SDK сокращает объём кода: хуки дают принуждение без собственного движка

## Альтернативы

1. **TypeScript + Agent SDK (TS-версия):** SDK доступен, но Python-экосистема для CLI-автоматизации зрелее
2. **Собственный движок без SDK:** большой объём кода, дублирование функциональности SDK
3. **LangChain / CrewAI:** избыточная абстракция, хуже контроль над принуждением цикла

## Последствия

- CI: pytest + ruff + mypy
- Минимальная версия Python: 3.11
- Зависимость от Claude Agent SDK (API-only, без GUI)
- Целевой проект — произвольный стек (через конфиг)
